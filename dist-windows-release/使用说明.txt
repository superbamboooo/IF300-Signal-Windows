IF300 多策略交易信号系统 Windows版本
=====================================

版本: MultiStrategy v1.0 (2026-02-08 更新)

最新改进:
---------
1. 修复GUI界面日期显示：现在显示今天日期，而不是数据库中的最后日期
2. 改进数据更新逻辑：从前一个交易日开始重新更新，确保最后一天是完整的收盘K线数据

使用方法:
--------
1. 将 MultiStrategy.exe 下载到本地
2. 双击运行
3. 程序会自动加载IF300期货数据并显示交易信号

系统要求:
--------
- Windows 7 或更高版本
- 至少 4GB 内存
- 网络连接（用于数据更新）

功能说明:
--------
- IF300 期货交易信号识别
- 周末效应策略分析
- 实时数据更新
- K线图表展示
- 多策略信号对比

数据更新:
--------
程序启动时会自动检查并更新最新的交易数据。
如果需要手动更新，点击界面上的"更新数据"按钮。

问题排查:
--------
如果遇到任何问题，请检查：
1. 网络连接是否正常
2. 防火墙是否阻止了程序运行
3. 是否有足够的磁盘空间

----------------
完整的源代码和详细的技术文档可在以下位置获得:
