================================================================================

【问题】
Windows EXE 版本点击"更新数据"失败，提示"数据文件不存在"或无反应

【根本原因】
1. GitHub Actions 构建配置没有打包 data 文件夹
2. 数据路径查找逻辑在打包后失效
3. 缺少错误日志和诊断工具

【已修复】
✅ 改进了 get_data_path() 函数，支持多种路径查找
✅ 更新了 GitHub Actions 配置，正确打包 data 文件夹
✅ 添加了详细的日志和诊断工具

================================================================================
【常见问题快速解答】
================================================================================

Q: 下载的是 MultiStrategy.exe（单文件）可以用吗？
A: 不行。新版本是整个 MultiStrategy/ 文件夹。
   如果只有 .exe，说明下载的是旧版本，重新下载。

Q: 为什么要有 data/ 文件夹？
A: 里面是历史K线数据（CSV格式）。
   没有这个文件夹，程序无法正常运行。

Q: 提示"权限被拒绝"怎么办？
A: 把 MultiStrategy/ 文件夹移到 Desktop 或 Documents
   不要放在 C:\Program Files 等系统保护目录

Q: 可以移动或重命名文件夹吗？
A: 可以。
   - 可以重命名整个 MultiStrategy/ 文件夹
   - 不要移动或删除其中的子文件夹和文件
   - 整个文件夹要放在一起

Q: 网络无法连接怎么办？
A: 1. 检查网络连接
   2. 检查防火墙/代理设置
   3. 如果连其他网站也不行，先解决网络问题

Q: 仍然无法更新，在非交易时间？
A: 检查当前时间和日期
   - 周末无法更新（周一-周五才能更新）
   - 非交易时间无法更新（15:00后可以）
   - 假日无法更新（春节/国庆等）

【进阶：本地打包（可选）】
================================================================================

如果想自己打包 Windows 版本：

1. 确保安装了 Python 3.10+ 和以下包：
   pip install pandas numpy matplotlib requests pyinstaller

2. 在 IF300 文件夹运行：
   pyinstaller --noconfirm --onedir --windowed --name "MultiStrategy" \
     --add-data "data_updater.py;." \
     --add-data "weekend_data_updater.py;." \
     --add-data "strategy_if300.py;." \
     --add-data "strategy_weekend.py;." \
     --add-data "data;data" \
     signal_app_main.py

3. 等待完成，在 dist/ 文件夹中找到 MultiStrategy/
